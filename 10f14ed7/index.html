图论

|字数总计:1.8k|阅读时长:8分钟|阅读量:

简要

  • 简单温习离散数学图论相关内容，图论知识可以用在数据结构 图 和 树(特殊的图) 中
  • 在后续的数据结构介绍中，大概率也用不到这么多知识，也存在有些必备知识没有罗列出来的情况，后续在介绍数据章节缺什么就补什么

参考书籍/资料/网站

  • Discrete Mathematics (Gary Chartrand, Ping Zhang)
  • OI Wiki 图论相关概念

定义

  • G=(V,E)G = (V, E)G=(V,E)

    在此仅研究有限图，即 V 和 E 是有限集合

  • 顶点(vertex) 集合 V/V(G)={vx,1≤x≤n}V/V(G) = \{v_{x}, 1 \le x \le n \}V/V(G)={vx​,1≤x≤n}, 非空集合
  • 边(edge) E/E(G)={(vx,vy),vx∈V,vy∈V}E/E(G) = \{(v_{x}, v_{y}), v_{x} \isin V, v_{y} \isin V \}E/E(G)={(vx​,vy​),vx​∈V,vy​∈V}
  • 图 G 的顶点数 ∣V(G)∣|V(G)|∣V(G)∣ 称为图 G 的 阶(order), 边数 ∣E(G)∣|E(G)|∣E(G)∣ 称为图 G 的 大小(size)

部分图分类

无向图(undirected graph)

  • EEE 中的每个元素 (vx,vy)(v_{x}, v_{y})(vx​,vy​) 是无序的，称为 无向边(undirected edge)

有向图(directed graph)

  • EEE 中的每个元素 (vx,vy)(v_{x}, v_{y})(vx​,vy​) 是有序的，称为 有向边(directed edge), vxv_{x}vx​ 和 vyv_{y}vy​ 分别称为 起点(initial vertex) 和 终点(terminal vertex)

简单图

没有 自环 和 重边 的图

  • 自环(loop): 存在边 e=(x,x),e∈Ee = (x, x), \quad e \isin Ee=(x,x),e∈E
  • 重边(multiple edge): 满足 e1=e2,e1,e2∈Ee_{1} = e_{2}, \quad e_{1}, e_{2} \isin Ee1​=e2​,e1​,e2​∈E

子图

G=(V,E)G = (V, E)G=(V,E), 存在图 H=(V′,E′),V′⊆V,E′⊆EH = (V', E'), V' \sube V, E' \sube EH=(V′,E′),V′⊆V,E′⊆E, 记作 H⊆GH \sube GH⊆G

  • 导出子图/诱导子图(induced subgraph): 满足 ∀vx,vy∈V′,\forall{v_{x},v_{y}} \isin V',∀vx​,vy​∈V′, 若 (vx,vy)∈E(v_{x},v_{y}) \isin E(vx​,vy​)∈E, 则 (vx,vy)∈E′(v_{x},v_{y}) \isin E'(vx​,vy​)∈E′, 即图 GGG 中，连接两个包含在 V′V'V′ 的顶点的边 eee，必然存在于 E′E'E′ 中
  • 生成子图/支撑子图(spanning subgraph): 满足 V′=VV' = VV′=V

完全图

一个图的所有顶点两两相邻

性质

相邻(adjacent)

  • 若 (vx,vy)∈E(v_{x},v_{y}) \isin E(vx​,vy​)∈E, 则顶点 vxv_{x}vx​ 和 vyv_{y}vy​ 相连，vxv_{x}vx​ 和 vyv_{y}vy​ 是 相邻(adjacent) 的
    • 与顶点 vvv 相邻的顶点集合称为 vvv 的 邻域(neighborhood)，记作 N(v)N(v)N(v)

    在有向图中，顶点xy相邻，不一定代表x可到达y(或y可到达x)，有向图的相邻概念需要区分方向

  • 若 (w,x),(y,z)∈E(w, x), (y, z) \isin E(w,x),(y,z)∈E, 有 (w,x)∩(y,z)≠∅(w, x) \cap (y, z) \ne \empty(w,x)∩(y,z)=∅, 则边 (w,x)(w, x)(w,x) 和 (y,z)(y, z)(y,z) 是 相邻 的

度(degree)

度(degree) 表示的是与一个顶点 vvv 相邻的其它顶点数量(或是与该顶点关联的边的数量)，记作 d(v)/deg(v)/degG(v)d(v) / deg(v) / deg_{G}(v)d(v)/deg(v)/degG​(v)

  • 若 d(v)=0d(v) = 0d(v)=0, vvv 为 孤立点(isolated vertex)
  • 若 d(v)=1d(v) = 1d(v)=1, vvv 为 叶节点(leaf vertex)/悬挂点(pendant vertex)
  • 在一个图中，所有顶点度数的最小值称为 最小度(minimum degree), 最大值称为 最大度(maximum degree), 分别记作 δ(G)=min⁡v∈Vd(v)\delta(G) = \min_{v \isin V}d(v)δ(G)=minv∈V​d(v), Δ(G)=max⁡v∈Vd(v)\Delta(G) = \max_{v \isin V}d(v)Δ(G)=maxv∈V​d(v)

无向图

  1. 在无向简单图中, d(v)=∣N(v)∣d(v) = |N(v)|d(v)=∣N(v)∣
  2. 在任意无向图 G=(V,E)G = (V, E)G=(V,E) 中, ∑v∈Vd(v)=2∣E(G)∣\sum_{v \isin V}d(v) = 2|E(G)|∑v∈V​d(v)=2∣E(G)∣

有向图

  1. 以一个顶点作为起点的边的条数称为 出度(outdegree), 记作 d+(v)d^{+}(v)d+(v); 以一个顶点作为终点的边的条数称为 入度(indegree), 记作 d−(v)d^{-}(v)d−(v), 有 d+(v)+d−(v)=d(v)d^{+}(v) + d^{-}(v) = d(v)d+(v)+d−(v)=d(v)
  2. 在任意有向图 G=(V,E)G = (V, E)G=(V,E) 中, ∑v∈Vd+(v)=∑v∈Vd−(v)=∣E(G)∣\sum_{v \isin V}d^{+}(v) = \sum_{v \isin V}d^{-}(v) = |E(G)|∑v∈V​d+(v)=∑v∈V​d−(v)=∣E(G)∣

路径(path)

途径(walk)

连接一连串顶点的边的序列 w=e1,e2,...,ekw = e_{1}, e_{2}, ..., e_{k}w=e1​,e2​,...,ek​, 使得存在一个顶点序列 v0,v1,...,vkv_{0}, v_{1}, ..., v_{k}v0​,v1​,...,vk​, 满足 ei=(vi−1,vi),i∈[1,k]e_{i} = (v_{i-1}, v_{i}), i \isin [1, k]ei​=(vi−1​,vi​),i∈[1,k] (或 v0→v1→v2→...→vkv_{0} \rightarrow v_{1} \rightarrow v_{2} \rightarrow ...\rightarrow v_{k}v0​→v1​→v2​→...→vk​), kkk 为途径长度

迹(trail)

对于途径 www, e1,e2,...,eke_{1}, e_{2}, ..., e_{k}e1​,e2​,...,ek​ 两两不同

路径(path)/简单路径(simple path)

对于途径 www, 连接的点的序列两两不同

回路(circuit)

对于途径 www, v0=vkv_{0} = v_{k}v0​=vk​

环/圈(cycle)/简单回路/简单环(simple circuit)

对于 回路 www, v0=vkv_{0} = v_{k}v0​=vk​ 是点序列中唯一重复出现的点对(也就是途径中只有一个圈)

连通(connected)

无向图

  • 无向图 G=(V,E)G = (V, E)G=(V,E) 中，对于 u,v∈Vu, v \isin Vu,v∈V, 若存在途径使得 v0=u,=vk=vv_{0} = u, = v_{k} = vv0​=u,=vk​=v, 则称 u,vu, vu,v 是连通的(顶点与自身连通，边上的两个顶点连通)
  • 若无向图 GGG 中任意两个顶点均连通，那么 GGG 是连通图
  • 若 HHH 是 GGG 的连通子图，且不存在连通图 FFF 满足 H⊂F⊆GH \sub F \sube GH⊂F⊆G, 则称 HHH 是 GGG 的一个 连通块/连通分量(connected component) (极大连通子图)

有向图

  • 有向图 G=(V,E)G = (V, E)G=(V,E) 中，对于 u,v∈Vu, v \isin Vu,v∈V, 若存在途径使得 v0=u,=vk=vv_{0} = u, = v_{k} = vv0​=u,=vk​=v, 则称 uuu 可达 vvv (顶点可达自身，边上的起点可达终点，无向图的连通视为双向可达)
  • 若有向图中顶点两两互相可达，称该图是 强连通(strongly connected) 的
  • 若有向图中的边替换为无向边后是连通图，称该无向图是 弱连通(weakly connected) 的
  • 强连通分量(strongly connected component), 弱连通分量(weakly connected component)

割(cut)

  • 连通图 G=(V,E)G = (V, E)G=(V,E), 若从 GGG 中删除点集 V′(V′⊆V)V'(V' \sube V)V′(V′⊆V) 后 G[V\V′]G[V \backslash V']G[V\V′] 不是连通图，称 V′V'V′ 为 GGG 的 点割集(vertex cut/separating set), 大小为一的点割集称为 割点(cur vertex)
  • 连通图 G=(V,E)G = (V, E)G=(V,E), 若从 GGG 中删除边集 E′(E′⊆E)E'(E' \sube E)E′(E′⊆E) 后 G′=(V,E\E′)G' = (V, E \backslash E')G′=(V,E\E′) 不是连通图，称 E′E'E′ 为 GGG 的 边割集(vertex edge set), 大小为一的边割集称为 桥(bridge)

遍历

  • 深度优先搜索(Depth First Search, DFS): 每次都尝试往更深的结点走
  • 广度优先搜索(Breadth First Search, BFS): 每次都尝试访问同一层结点
    • 找到的路径是从起点开始的 最短 合法路径
